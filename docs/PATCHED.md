# Patched bindings

The bindings are generated by [runic](https://github.com/Samudevv/runic) from the C headers.
Regenerating overwrites hand fixes, so each is also pinned by a typed variable in the
package's `patched.odin`: a regeneration that drops a patch fails to compile there instead
of misbehaving at run time.

To regenerate, run `make generate` and then `make ci`.

## Generation rules

`scripts/postprocess.sh <pkg>` applies these to `<pkg>/<pkg>.odin`. They are odin-gtk's rules,
trimmed to what runic 0.8 produces from the system headers.

| package | rule | reason |
|---|---|---|
| `atk` | `^glib.char` and `[^]glib.char` become `cstring` | `gchar *` is a typedef'd char pointer, which runic leaves as a pointer to `char` |
| `atk` | backticks, parentheses and `atk_` prefixes dropped from `TYPE_*`, `*_VERSION`, `*_AGE`, `VERSION_*`; `VAR` and the `atk_*_version`/`atk_*_age` strings deleted | macro text runic quotes as a string |
| `atk` | `Foo :: _AtkFoo` is deleted and `_AtkFoo` becomes `Foo` | one name per struct |
| `gtk3` | `^glib.char` and `[^]glib.char` become `cstring` (`atk` likewise) | as above |
| `gtk3` | `dkFoo` becomes `GdkFoo` | runic trims the `G` of `GdkFoo` as it trims that of `GFoo`; see DECISIONS §3 |
| `gtk3` | `_GtkFoo` becomes `Foo`, `_GdkFoo` becomes `GdkFoo`, and the resulting `Foo :: Foo` is deleted | one name per struct; `_GdkAtom` keeps its underscore, because `GdkAtom` is the pointer typedef |
| `gtk3` | `cairo.cairo_t` becomes `cairo.context_t`, `cairo.cairo_X_t` becomes `cairo.X_t`, `pixbuf.GdkFoo` becomes `pixbuf.Foo`, `atk.AtkFoo` becomes `atk.Foo`, `pango.PangoFoo` becomes `pango.Foo` | the names the sibling bindings declare; runic does not trim types it takes from other packages |
| `gtk3` | `TYPE_*` and `GDK_TYPE_*`, and `*_ERROR` lose backticks, parentheses and `gtk_`, so `TYPE_FOO` names `foo_get_type` | macro text runic quotes as a string |
| `gtk3` | `STOCK_*` become plain string constants; `GDK_EVENT_STOP`, `GDK_EVENT_PROPAGATE`, `ENTRY_BUFFER_MAX_SIZE`, `UNIT_PIXEL` and the other quoted macros lose their backticks and C casts | macro text runic quotes as a string |
| `gtk3` | `GDK_SELECTION_TYPE_*` and the other `((GdkAtom)((gpointer) (gulong) (N)))` macros become `GDK_X := GdkAtom(uintptr(N))` | a pointer cannot be an Odin constant, so these are package variables |
| `gtk3` | `Module*` and `_GModule` are deleted; `g_module_*` and `GMODULE*` are ignored in `rune.yml` | GTK's headers include GModule, which odin-glib does not bind (its decision 7) |
| `atk`, `gtk3` | the GFlags enums listed in `postprocess.sh` (`atk_flags`, `gtk3_flags`) become `FooBit :: enum u32` of bit indices plus `Foo :: bit_set[FooBit; u32]`; zero members and composite masks become constants of `Foo` under their C names | `{.SHIFT_MASK, .CONTROL_MASK}` instead of u32 ORs; the size and bits are those of C; see DECISIONS §8 |
| `gtk3` | `state: glib.uint_` in `GdkEventMotion`, `GdkEventButton`, `GdkEventTouch`, `GdkEventCrossing`, `GdkEventTouchpadSwipe` and `GdkEventTouchpadPinch` becomes `GdkModifierType` | C declares `guint state`; the value is a modifier mask of the same size (`GdkEventKey` and `GdkEventScroll` are in `hand.odin`) |
| `gtk3` | `foreign import` names `gtk-3` and `gdk-3` | the GDK procedures live in `libgdk-3.so`, which the linker does not reach through `libgtk-3.so` |
| `atk`, `gtk3` | `parameters: declared` in `atk/rune.yml` and `gtk3/rune.yml` makes every procedure parameter `^T` (`T **` is `^^T`); only the 81 parameters of the procedures listed under `to.detect.arrays` are `[^]`; the parameters in `scripts/single-object-params.*.txt` are pinned once per type in `patched.odin` | runic writes `[^]T` for any pointer parameter whose name ends in `s` (`settings`, `bounds`, `focus`, `n_types`...), and `[^]^T` for `T **`; a `[^]` on one object lets a caller index past it. The arrays were chosen against the C headers and the gtk-doc `(array)` annotations; `scripts/check-generated.sh` fails if a `[^]` parameter is not in `arrays:` or a listed single object is `[^]` again. Function-pointer types are always `^T` in this mode, so `param_rules` in `postprocess.sh` gives their parameters the types runic's name guess wrote before (`[^]T`, which includes the real arrays: `colors`, `uris`, `pts`, `attribute_names`); a row that matches nothing fails generation |
| `atk`, `gtk3` | a procedure whose last C parameter is a `va_list` is not generated; the foreign block carries a `// name skipped` comment | runic drops a trailing `va_list` and marks the procedure `#c_vararg ..any`, which is a wrong call; the fork skips it, and `check-generated.sh` holds the list of skipped names. Real `...` procedures (`list_store_insert_with_values`) are bound |

## `atk`

No hand-written code.

## `gtk3`

`rune.yml` overwrites six structs that have bit fields, which runic cannot lay out, with arrays
of their x86_64 size and alignment: `RcStyle` (384 bytes), `ContainerClass` (976),
`MenuShellClass` (1088), `MenuItemClass` (1112), `TableChild` (24) and `TableRowCol` (8). Their
fields are not reachable from Odin. The pins are `patched_rc_style`, `patched_container_class`,
`patched_menu_shell_class`, `patched_menu_item_class`, `patched_table_child` and
`patched_table_row_col` in `gtk3/patched.odin`; a test checks the sizes against `sizeof` of the C
structs. A widget subclass cannot override `ContainerClass`, `MenuShellClass` or `MenuItemClass`
vfuncs from Odin until these are laid out field by field.

Six structs whose bit fields sit among usable fields are declared by hand in `gtk3/hand.odin`,
with Odin `bit_field`s: `GdkEventKey`, `GdkEventScroll`, `TextAppearance`, `TextAttributes`,
`BindingSet` and `BindingEntry`. `GdkXEvent` (`void` in C) is an empty struct there. `rune.yml`
overwrites the generated versions with one-byte placeholders that `postprocess.sh` deletes, so a
regeneration that emits one of these names too fails to compile with a redeclaration. A test
checks every size and the offsets of the fields after a bit field.

`gtk_main`, `gtk_true` and `gtk_false` keep their C names: trimmed, they would be `main`,
`true` and `false`, which Odin reserves. The pins are `patched_main`, `patched_true` and
`patched_false`.
