# Spec — odin-gtk3

## Packages

```
atk/    package atk: ATK 2.52.0, generated by runic from atk/rune.yml
gtk3/   package gtk3: GTK 3 and GDK 3, generated by runic from gtk3/rune.yml, plus hand.odin
```

Import through the `gtk3` collection: `import "gtk3:<package>"`.

## Surface

Every public declaration of the bound headers (GTK 3 and GDK 3.24.41, ATK 2.52.0), named as runic names
them, plus the hand fixes in [PATCHED.md](PATCHED.md). Deprecated API is bound, because
`GLIB_DISABLE_DEPRECATION_WARNINGS` is set when generating.

GTK's names are trimmed of `Gtk`/`gtk_`/`GTK_`; GDK's keep `Gdk`/`gdk_`/`GDK_`
([DECISIONS §3](DECISIONS.md)). Not bound: GModule, and the headers `gtk.h` does not include
(GtkUnixPrint, GDK's X11, Wayland and Broadway backends, GtkX).

## Version

The binding records the library versions it was generated from, GTK in the README's
`**Bound version:**` line and ATK in its `**Bound ATK version:**` line. `make test` compares each
with the version macros of the installed headers and with the loaded library.
